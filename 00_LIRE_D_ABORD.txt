│ 📌 VOUS AVEZ REÇU UNE APPLICATION COMPLÈTE                                │
└────────────────────────────────────────────────────────────────────────────┘

Cette application Streamlit permet de :
  ✅ Calibrer des réservoirs cylindriques horizontaux
  ✅ Générer des tableaux de jaugeage complets
  ✅ Créer des courbes de calibration
  ✅ Valider selon ISO 12917-1:2017
  ✅ Exporter en CSV/Excel/TXT

┌────────────────────────────────────────────────────────────────────────────┐
│ 🚀 DÉMARRAGE EN 30 SECONDES                                               │
└────────────────────────────────────────────────────────────────────────────┘

WINDOWS :
  1. Double-cliquez sur : run.bat
  → L'application s'ouvre automatiquement

macOS / LINUX :
  1. Terminal → cd [dossier de l'application]
  2. bash run.sh
  → L'application s'ouvre automatiquement

TOUS LES SYSTÈMES (manuel) :
  1. Terminal/Command Prompt → cd [dossier]
  2. pip install -r requirements.txt
  3. streamlit run streamlit_app.py
  → Ouvrez http://localhost:8501

┌────────────────────────────────────────────────────────────────────────────┐
│ ⚡ EXEMPLE RAPIDE (PRÊT À COPIER)                                          │
└────────────────────────────────────────────────────────────────────────────┘

Entrez ces valeurs pour tester immédiatement :

1ère lecture de circonférence : 10.502 m
2e lecture : 10.504 m
3e lecture : 10.501 m
Longueur cylindre : 10.0 m
Type de têtes : Elliptique
Longueur des têtes : 0.835 m
Tilt : 1.5°

→ Résultat : Capacité totale de ~97,000 litres

Avant de lancer l'application :

  □ Python 3.8+ installé (python --version)

  □ Internet disponible (pour installer dépendances)
  □ Port 8501 libre
  □ Terminal/Command Prompt accessible
  □ Navigateur web fonctionnel

"Command not found: python"
  → Installer Python depuis https://python.org

"ModuleNotFoundError: No module named 'streamlit'"
  → Exécuter : pip install -r requirements.txt

Port 8501 occupé
  → Exécuter : streamlit run streamlit_app.py --server.port 8502

Autres problèmes
  → Lire : README.md § "Dépannage"
  → Ou lancer : python test_dependencies.py
